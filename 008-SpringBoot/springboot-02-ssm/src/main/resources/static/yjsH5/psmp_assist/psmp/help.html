无障碍操作说明

一、无障碍操作概述

1.什么是信息无障碍？

所谓的信息无障碍是指无论健全人还是残疾人、无论年轻人还是老年人都能够从信息技术中获益，任何人在任何情况下都能平等地、方便地、无障碍地获取信息、利用信息。

2.什么是网页无障碍？

所谓的网页无障碍是指残疾人、有特殊需求的健全人可以获取网页上的任何信息，为了做到这一点，就要实现网页内容无障碍以及上网使用的辅助软件技术的无障碍。

3.本网站无障碍功能？

本网站主要实现了以下两个方面的无障碍功能：

> 无障碍强化导航功能

> 无障碍网站浏览辅助功能

4.无障碍强化导航功能包含哪些内容？

> 完全支持鼠标操作，支持键盘控制，更方便的照顾特殊群体的使用习惯。

5.无障碍网站浏览辅助功能包含哪些内容？

> 提供开启、关闭无障碍网站浏览辅助工具的功能；

> 提供无障碍浏览说明；

> 提供前进、后退功能；

> 提供刷新功能；

> 提供切换鼠标箭头功能；

> 提供辅助光标功能；

> 提供纯文本功能；

> 提供配色功能；

> 提供放大、缩小功能；

> 提供语音调节功能；

> 提供指读、连读功能；

> 提供显示屏功能。

> 提供全屏功能。

> 提供灰度调节功能。

6.如何使用网站浏览辅助工具条？

在网站顶部，设置“无障碍”开关，可通过点击该链接开启无障碍网站浏览辅助工具。

7.弱视人群和老年人用户如何浏览本网站？

本网站专门为视力障碍人群、文化程度较低人群提供了无障碍网站浏览辅助功能，网站用户可以通过网站浏览辅助工具调整页面大小、选择文字与背景色高对比提高网页内容辨识、开启光标辅助横排及竖排文字读取、开启显示屏翻译文字，此外，浏览者还可以根据自己的需要选择是否以语音播报的方式获取网页中的信息。

二、无障碍操作说明

本网站为使盲人、老年人、弱视人群等特殊群体能够更加便捷的访问本网站，本功能适用但不限于使用辅助软件的用户，它在基本保持原网页布局效果上，为拥有辅助工具的用户提供完整网站内容和便捷的操作,提供了以下快捷键设置：

1.辅助工具

跳转首页： 快捷键(Alt + Shift + ` ) 跳转帮助： 快捷键(Alt + Shift + /)

退出辅助工具： 快捷键(Alt +Shift + q) 页面后退： 快捷键(Alt + Shift + ,)

页面前进： 快捷键(Alt + Shift + .) 刷新页面： 快捷键(Alt + Shift + 1)

切换光标： 快捷键(Alt + Shift + 2 ) 纯文本模式： 快捷键(Alt + Shift + 3)

切换配色： 快捷键(Alt + Shift + 6 ) 向上选择配色： 快捷键(Alt + Shift + ↑)

向下选择配色： 快捷键(Alt + Shift + ↓ ) 页面放大： 快捷键(Alt + Shift + 7)

页面缩小： 快捷键(Alt + Shift + 8) 音量大小调节： 快捷键(Alt + Shift + 9)

语音调节： 快捷键(Alt + Shift + 0 ) 加快语速： 快捷键(Alt + Shift + → )

减缓语速： 快捷键(Alt + Shift + ←) 指读： 快捷键(Alt + Shift + -)

连读： 快捷键(Alt + Shift + = ) 切换显示屏： 快捷键(Alt + Shift + [)

切换全屏： 快捷键(Alt + Shift + ] ) 灰度调节： 快捷键(Alt + Shift + | )（灰度调节功能暂不支持ie10和ie11浏览器,ie8和ie9浏览器中只有两档调节）
